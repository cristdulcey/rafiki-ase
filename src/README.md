# Rafiki ASE

Requiments
------------

- Docker
- Docker Compose
- Instance of Rafiki

Installation
------------

1. Clone the repository:
   ```bash
    git clone [REPOSITORY_URL]
    cd rafiki-ase
```

2. Configure the environment variables:
   ```bash
    cp .env.example .env
    # Edit the .env file to set your Rafiki instance URL and other configurations
   ```
